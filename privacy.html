Informativa sulla privacy

wyrelab ricerca-auto è un'applicazione personale: l'unico utente è il suo proprietario, e nessun altro può usarla.

Quali dati legge

Tramite la Gmail API legge, nella casella del proprietario, le mail di avviso dei portali di annunci auto, e aggiunge un'etichetta a quelle già elaborate. Non legge altre caselle.

Come li usa

Dalle mail ricava gli identificativi degli annunci, che sono dati pubblici dei portali, e li salva in un database privato del proprietario. Il contenuto delle mail resta nella casella e nei registri tecnici del server del proprietario.

Condivisione

Nessun dato viene venduto, ceduto o condiviso con terzi, né usato per pubblicità. L'uso dei dati ricevuti dalle API di Google rispetta le Google API Services User Data Policy, compresi i requisiti di uso limitato (Limited Use).

Revoca

L'accesso si revoca in qualunque momento da myaccount.google.com/permissions.

Personal application with a single user, its owner. Through the Gmail API it reads car-listing alert emails in the owner's inbox and labels them once processed; listing identifiers are stored in the owner's private database. No data is sold, transferred or shared with third parties, and use of data from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from myaccount.google.com/permissions.
